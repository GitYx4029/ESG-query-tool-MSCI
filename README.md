# ESG 行业议题公益工具

免费查询行业相关 ESG 议题、阅读公开方法学来源。独立整理，非 MSCI 官方产品，信息以原始资料为准。

企业分析暂通过管理员入口开放，示例为纯虚构数据；用户上传 Excel 在浏览器本地解析。AI调用需要另行配置服务器。

- [AI 分析接入](docs/AI_ANALYSIS_SETUP.md)
