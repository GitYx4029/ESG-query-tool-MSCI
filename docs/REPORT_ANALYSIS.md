# 独立报告对照分析 · v1.11

入口 `/report-analysis`，首页首位卡片与桌面/移动导航均可到达。不需要评分Excel或管理员密码。企业分析中已移除报告上传、对照按钮和旧模型调用。

## 用户流程

1. 选择一份PDF（不超过80MiB、600页），或最多20张按选择顺序排列的PNG/JPG/WebP（每张20MiB，合计80MiB）。
2. PDF文字层在浏览器提取一次；文字不足的页面自动OCR前8页，其余可按文件页序每批识别20页。中英文识别引擎和字库由本站提供，按需加载。
3. 根据报告业务描述给出最多3个行业候选，附原文与文件页码；用户确认或手动选择。行业映射沿用项目参考数据，不能视为MSCI官方企业分类。
4. 对照行业的相关议题，展示逐项要求、原文、物理页码和识别可信度；支持补充关键词、查看原页和CSV导出。

文件与索引只保留在当前页面内存；离开或刷新页面后需重新上传，不写浏览器持久存储或后端数据库。OCR语言资源会缓存，报告不会缓存。没有恢复匿名行为采集；用户主动提交的反馈只记录行业、页面和填写内容。

## 判断范围

33个议题均有项目整理的核验清单。绿色建筑、职业健康与安全、产品安全与质量、商业道德增加更具体的范围、分母、承包商等要求。清单是披露审阅工具，不是官方完整评分规则，也不输出MSCI评级、分值或权重。

本地结果表示“找到相关线索／本次未检索到／识别或依据不足”。关键词出现不能判为充分披露。目录和标准索引页不作为证据；绩效数据表保留。未识别页面或低可信度OCR存在时，不把缺少检索结果解释为未披露。治理议题可能需要年报、公司治理报告等其他资料。

页码使用文件的第1、2、3…页，不假定与报告印刷页码一致。图片版按文件选择顺序作为页序。OCR置信度只是识别引擎估计，需要核对原页；图片中的复杂表格、繁体文字、小字与模糊照片可能遗漏。

这些skill是工作流和脚本集合，不能直接安装到静态网页里运行。本次将适用原则转成浏览器模块、核验数据与后端契约。

## 可选AI精读与成本

轻量后端新增 `GET /api/report/health` 和 `POST /api/report/analyze`，只精读一个议题的最多5项要求、每项最多4段证据，引用必须逐字存在于提交片段中。最大输入15,000字符，输出按指标数限制。30秒上游超时，取消或失败保留本地结果。

同一页面同一报告/行业/议题/框架版本复用精读结果。修改报告、行业或OCR范围后重新核验。不会按议题重复发送整份PDF。公网模型调用设置每IP每小时20次的临时限制，以及数据库每日200次总预算；数据库仅保存日期和总调用次数，保留3天，无报告、片段、IP或用户标识。

在已有Sites后端配置三个运行变量：`REPORT_AI_BASE_URL`（HTTPS、OpenAI兼容的API基础路径，如供应商的/v1）、`REPORT_AI_MODEL`、`REPORT_AI_API_KEY`（secret）。不把密钥放到GitHub、前端、构建变量或聊天中。无须安装插件；不要把旧企业入口密码作为模型服务凭证。模型账号的数据保留政策由服务商决定。

本次后端无模型凭证，所以真实模型调用尚未验收；页面如实显示AI精读未启用。本地识别与披露证据对照可独立运行。精读接口的协议、引用核验、故障与预算测试使用模拟上游，不代表模型真实语义质量。

## 验收记录

- 中文文字PDF：4页，PDF.js真实提取约659ms；识别房地产候选，员工/承包商死亡人数0的原文位于文件第3页。
- 扫描PDF：2页，确认没有文字层；原页PNG经Tesseract.js真实中英文OCR约1.36秒，置信度92，面积、零死亡人数与LTIR均识别。时间为测试容器结果，首次浏览器加载引擎及手机性能会影响耗时。
- 公开样本：[太古地产2025可持续发展报告](https://sd.swireproperties.com/2025/en/download-centre)：409页，53.6MiB。PDF.js真实提取970,598字符约4.49秒；本地行业候选及12议题、40项证据检索约165ms。发现并修复“media/immediate”误判、物业投资候选遗漏、索引页混入和绩效表被误排除。
- 当前真实模型密钥缺失；不把接口模拟测试或本地关键词检索标作AI语义分析成功。

代码测试包含：全部议题覆盖、目录/索引排除、数字0、英文检索、物理页码、低可信度/未识别页、引用伪造/缺项/重复项、未配置模型、上游失败、隐私载荷拒绝和每日预算上限。保留企业分析密码保护、原有Excel真实评分与匿名统计暂停行为。

可重复执行：`npm run check`；`npm test`；`npm run report:assets`；`npm run build`。准备测试文件后执行 `npm run report:qa -- /absolute/path/to/fixtures`（text-report.pdf、scanned-report.pdf、report-page-3.png）。公开报告仅用于验收，不提交到仓库。

增加简繁体及中文字符间空格的检索归一化（引用保留原文）、服装与逆变器/储能业务候选、基于文字坐标的绩效表行列复原。数字类核验项优先展示表格行；职业安全示例要素保留年度、单位、员工/承包商范围，不将一般安全事故率改称LTIR。
